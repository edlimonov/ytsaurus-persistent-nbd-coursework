# Персистентные NBD-тома в джобах YTsaurus

**Владелец:** Наиль Зарипов. **Статус:** рабочий пакет КТ-1/КТ-2, 24.11.2026. **Кодовая база:** форк YTsaurus; техническая опора при подготовке — внутренняя ветка `vk-25.3-nbd`, коммит `c983b610de7`. Публичный PR ещё не создан. Внутренние адреса, названия кластеров и сведения о пользователях в этот пакет не включены.

## Назначение

Пользователь YTsaurus задаёт персистентный блочный том на основе динамической таблицы и монтирует его в джобу. При повторном запуске джобы с тем же идентификатором устройства данные остаются доступными. В MVP рассматриваются корневой NBD-диск, отдельные тома внутри sandbox и проверка ошибочной конфигурации. Путь к публичному PR и окончательная форма спеки будут сверены с актуальным upstream перед отправкой.

**Граница учебного проекта:** серверные компоненты YTsaurus (controller agent, exec node, job proxy, NBD server) и документированный YSON-интерфейс операции. По подтверждению автора, преподаватель засчитывает YTsaurus и тестовый стенд как сервисную часть и запускаемый каркас. Учебные документы хранятся в отдельной папке рядом с checkout YTsaurus; будущий публичный PR содержит изменения кода и необходимую документацию, а не весь учебный пакет. Фактический прогон, CI и теги ещё нужно предъявить.
